核心功能

为前端开发者和设计师打造的 SVG 优化体验

智能压缩

剥离注释、多余空白、元数据和编辑器残留数据，保留渲染必需的代码。

路径精度优化

将路径坐标从 0 到 6 位小数可调，在体积与精度之间自由取舍。

viewBox 修复

自动检测缺失的 viewBox，从 width/height 推算并补全。

Data URI 转换

一键将 SVG 转为 data:image/svg+xml 内联 URI，适合 CSS background 或 img src。

安全审计

检测 SVG 中的脚本和外部引用，帮你识别潜在风险。

100% 本地处理

全部计算在浏览器 WASM 中完成，SVG 内容不上传任何服务器。

安装与运行

需要 Rust 工具链和 wasm-pack。一行命令启动本地优化器。

1. 克隆并构建

# 克隆仓库
git clone https://github.com/Tinkora/svg_tidy.git
cd svg_tidy

# 构建 Web WASM
wasm-pack build --target web crates/svg_tidy_web

2. 启动本地服务器

cp crates/svg_tidy_web/pkg/* crates/svg_tidy_web/static/pkg/
cd crates/svg_tidy_web/static
python3 -m http.server 8080

# 浏览器打开 http://localhost:8080
